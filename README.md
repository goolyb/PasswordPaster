# Password Paster 📋

A simple Java-based automation script that pastes words from a file into any application.

## 🚀 How to Setup (Mac/Linux)

1. **Download/Clone** this folder.
2. Open your **Terminal** in this folder.
3. Run the installer:
   ```bash
   chmod +x install.sh
   ./install.sh
   ```
4. Refresh your terminal:
   ```bash
   source ~/.zshrc
   ```

## ⌨️ How to Use

1. Put your words/passwords in `passwords.txt`.
2. Type `passpaster` in your terminal.
3. You have **5 seconds** to click on the app where you want to paste (like Telegram, Discord, etc.).

## 🛠 Requirements
- Java 17 or higher
- Maven (`mvn`)
